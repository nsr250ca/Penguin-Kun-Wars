# Visual references

The 3D scene uses original procedural geometry and materials. The following official screenshots were used as visual references for the green table, wooden borders, pink balls, spectators, blue penguin, and mountain backdrop.

- [Nintendo: Arcade Archives Penguin-Kun Wars](https://www.nintendo.com/us/store/products/arcade-archives-penguin-kun-wars-switch/)
- [PlayStation: Arcade Archives Penguin-Kun Wars](https://store.playstation.com/en-us/product/UP0571-CUSA18063_00-HAMPRDC000000001)
- [Nintendo UK screenshot gallery](https://www.nintendo.com/en-gb/Games/Nintendo-Switch-download-software/Arcade-Archives-Penguin-Kun-Wars-1702139.html)

No screenshot, sprite, ROM, or music from those releases is bundled. This prototype is a visual reinterpretation, with simplified rules pending detailed arcade reference verification.
